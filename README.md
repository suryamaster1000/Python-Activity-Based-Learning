# Python Activity-Based Learning (ABL)

A collection of beginner-friendly Python case studies prepared for the Python ABL assignment.

## Projects

1. [Food Waste Monitoring System](Project-01-Food-Waste-Monitoring/README.md) — Case Study 53: track meals prepared, served, leftovers, and wastage percentage.
2. [Password Policy Validation Engine](Project-02-Password-Policy-Validation/README.md) — Case Study 29: validate sample passwords against documented rules.
3. [String-Based Examination Answer Evaluation](Project-03-String-Based-Examination-Answer-Evaluation/README.md) — Case Study 31: compare student answers with an answer key and calculate correct, incorrect, and unanswered responses.
4. [Multi-Stage Examination Eligibility System](Project-04-Multi-Stage-Examination-Eligibility/README.md) — Case Study 39: check attendance, laboratory completion, internal marks, and fee clearance and report all unmet requirements.
5. [Tuple-Based Product Catalogue Audit](Project-05-Tuple-Based-Product-Catalogue-Audit/README.md) — Case Study 49: use tuples to audit product IDs, details, prices, and stock.
6. [Student Feedback Sentiment Scoring](Project-06-Student-Feedback-Sentiment-Scoring/README.md) — Case Study 34: score feedback using a documented positive and negative keyword list.
7. [Student Marks Matrix Analysis](Project-07-Student-Marks-Matrix-Analysis/README.md) — Case Study 42: analyse student marks by rows and subjects using columns.
8. [Weekly Electricity Consumption Matrix](Project-08-Weekly-Electricity-Consumption-Matrix/README.md) — Case Study 45: summarize daily kWh readings across weeks and flag high-use days.
9. [ATM Transaction Sequence Simulation](Project-09-ATM-Transaction-Sequence-Simulation/README.md) — Case Study 13: simulate deposits, withdrawals, balance enquiries, and a transaction history.
10. [Energy Conservation Before-and-After Analysis](Project-10-Energy-Conservation-Before-After-Analysis/README.md) — Case Study 68: compare average daily energy use before and after changes.

## Run Project 04

~~~text
python Project-04-Multi-Stage-Examination-Eligibility/eligibility_checker.py
~~~

Project 04 uses demonstration assumptions: attendance at least 75%, all required laboratory activities completed, internal marks at least 20 out of 50, and fees cleared. These are not official university rules; confirm the actual requirements with faculty.

## Run Project 05

~~~text
python Project-05-Tuple-Based-Product-Catalogue-Audit/tuple_product_catalogue_audit.py
~~~

Project 05 flags duplicate IDs, blank name/category fields, invalid prices, negative stock, out-of-stock items, and low stock (1–5 units). These are example audit rules.

## Run Project 06

~~~text
python Project-06-Student-Feedback-Sentiment-Scoring/student_feedback_sentiment_scoring.py
~~~

Project 06 uses editable word lists and a simple score (positive matches minus negative matches). It does not understand context, sarcasm, or negation, so results need human review.

## Run Project 07

~~~text
python Project-07-Student-Marks-Matrix-Analysis/student_marks_matrix_analysis.py
~~~

Project 07 uses an example pass mark of 40 out of 100 in every subject. Confirm the actual grading rules with faculty.

## Run Project 08

~~~text
python Project-08-Weekly-Electricity-Consumption-Matrix/weekly_electricity_consumption_matrix.py
~~~

Project 08 flags daily readings above an example threshold of 15 kWh. This is an adjustable demonstration setting, not an official utility rule.

## Run Project 09

~~~text
python Project-09-ATM-Transaction-Sequence-Simulation/atm_transaction_sequence_simulation.py
~~~

Project 09 is a simulation only: it does not connect to a bank or access real funds.

## Run Project 10

~~~text
python Project-10-Energy-Conservation-Before-After-Analysis/energy_conservation_before_after_analysis.py
~~~

Project 10 compares average daily energy use in kWh/day for comparable periods and reports reductions as well as increases.

The programs use beginner-level Python concepts from the assigned syllabus. See each project's README for assumptions, run instructions, and test cases.
