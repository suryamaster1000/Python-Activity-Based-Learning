# Screenshots — Project 07

`sample_output_preview.svg` is a designed preview of example output, **not** an actual terminal screenshot.

To capture genuine evidence for submission:

1. Open a terminal in this project folder.
2. Run `python student_marks_matrix_analysis.py`.
3. Enter the three students and their marks from Test Case 1 in `test_cases.md`.
4. Capture screenshots showing the student-wise, subject-wise, and overall summaries.
5. Save them in this folder as `marks_matrix_terminal_1.png` and, if needed, `marks_matrix_terminal_2.png`.
6. Keep all marks, averages, and labels readable.

Do not present the designed preview as a genuine terminal screenshot.
