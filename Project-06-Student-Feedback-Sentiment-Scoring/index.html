Student Feedback Sentiment Scoring

Apply simple, transparent keyword rules to categorize student feedback comments.

Project files

Python sourceREADMEAlgorithm and pseudocodeTest casesFlowchartSample output preview

Scoring assumptions

  • Positive keyword match: +1
  • Negative keyword match: −1
  • Score above 0: positive; below 0: negative; zero: neutral

This beginner exercise does not understand context, sarcasm, or negation. Human review remains important.

Run the program

Use Python 3 in a terminal:

python student_feedback_sentiment_scoring.py
