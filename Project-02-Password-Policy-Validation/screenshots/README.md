# Screenshots — Project 02

`password_test_output.svg` is a designed summary of sample test outcomes, **not** a raw terminal screenshot.

To capture real evidence for submission:

1. Open a terminal in this project folder.
2. Run `python password_policy_validation.py`.
3. Enter the 10 sample passwords listed in `test_cases.md` (enter `10` for the count).
4. Capture readable screenshots that show each result and the completion message.
5. Save the screenshots in this folder as `password_validation_terminal_1.png` and `password_validation_terminal_2.png` as needed.

Never submit the designed SVG as if it were a real terminal screenshot. Do not enter any real account password.
