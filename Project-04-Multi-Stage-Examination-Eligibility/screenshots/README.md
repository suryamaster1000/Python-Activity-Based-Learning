# Output screenshots

After running eligibility_checker.py, capture genuine terminal screenshots showing:

1. An eligible student whose records satisfy all four requirements.
2. A not-eligible student with more than one unmet requirement.
3. The final summary with eligible/not-eligible counts and the student-wise report.

The sample_output_preview.svg file is a designed summary of the standard sample run, not a screenshot captured from a terminal. Add real screenshots from your computer if your faculty requires terminal screenshots.
