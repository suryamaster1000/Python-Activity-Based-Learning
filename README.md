# Python Activity-Based Learning (ABL)

A collection of beginner-friendly Python case studies prepared for the Python ABL assignment.

## Projects
1. [Food Waste Monitoring System](Project-01-Food-Waste-Monitoring/README.md) — Case Study 53.
2. [Password Policy Validation Engine](Project-02-Password-Policy-Validation/README.md) — Case Study 29.
3. [String-Based Examination Answer Evaluation](Project-03-String-Based-Examination-Answer-Evaluation/README.md) — Case Study 31.
4. [Multi-Stage Examination Eligibility System](Project-04-Multi-Stage-Examination-Eligibility/README.md) — Case Study 39.

## Run Project 01
    python food_waste_monitoring.py

## Run Project 02
    python password_policy_validation.py

## Run Project 03
    python string_based_exam_evaluation.py

## Run Project 04
    python multi_stage_exam_eligibility.py

Project 04 uses example eligibility thresholds: attendance >= 75%, at least one lab completed, internal marks >= 40/100, and fees cleared. These are not official university rules; see its README.

The programs use beginner-level Python concepts. Each project folder includes code, documentation, algorithm/pseudocode, flowchart, test cases, and run instructions. Output previews are labelled as previews; capture real terminal screenshots for submission.
