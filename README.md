# Python Activity-Based Learning (ABL)

A collection of beginner-friendly Python case studies prepared for the Python ABL assignment.

## Projects

1. [Food Waste Monitoring System](Project-01-Food-Waste-Monitoring/README.md) — Case Study 53: track meals prepared, served, leftovers, and wastage percentage.
2. [Password Policy Validation Engine](Project-02-Password-Policy-Validation/README.md) — Case Study 29: validate sample passwords against documented rules.
3. [String-Based Examination Answer Evaluation](Project-03-String-Based-Examination-Answer-Evaluation/README.md) — Case Study 31: compare student answer strings with an answer key, count correct, incorrect, and unanswered responses, and apply negative marking.

## Repository structure

- index.html — project directory website for GitHub Pages
- Project-01-Food-Waste-Monitoring/ — code and documentation for Case Study 53
- Project-02-Password-Policy-Validation/ — code, algorithm, pseudocode, flowchart, test cases, and documentation for Case Study 29
- Project-03-String-Based-Examination-Answer-Evaluation/ — code, algorithm, pseudocode, flowchart, test cases, sample output preview, and documentation for Case Study 31

## Run Project 01

Open a terminal in the first project folder and run:

~~~text
python food_waste_monitoring.py
~~~

## Run Project 02

Open a terminal in the second project folder and run:

~~~text
python password_policy_validation.py
~~~

## Run Project 03

Open a terminal in the third project folder and run:

~~~text
python string_based_exam_evaluation.py
~~~

Project 03 uses an assumed marking policy of +4 for a correct answer, -1 for an incorrect answer, and 0 for an unanswered question. These assumptions are documented in its README and can be changed if a teacher specifies another scheme.

The programs use beginner-level Python concepts from the assigned syllabus. See each project's README for assumptions, run instructions, and test cases.
