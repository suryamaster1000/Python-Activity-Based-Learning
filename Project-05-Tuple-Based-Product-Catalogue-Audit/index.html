Tuple-Based Product Catalogue Audit

Use tuples to keep product records together and find catalogue and stock issues.

Audit rules (assumptions)

  • IDs should be unique.
  • Name and category should not be blank.
  • Price must be greater than zero.
  • Stock of zero means out of stock; 1–5 units means low stock.

These are example rules for the assignment, not an official inventory policy.

Run the program

Use Python 3 in a terminal:

python tuple_product_catalogue_audit.py
