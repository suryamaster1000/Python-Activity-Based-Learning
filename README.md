# Python Activity-Based Learning (ABL)

A collection of Python case studies prepared for the Python ABL assignment.

## Projects

1. [Food Waste Monitoring System](Project-01-Food-Waste-Monitoring/README.md) — monitor meals prepared, meals served, leftovers, and wastage percentage.
2. [Password Policy Validation Engine](Project-02-Password-Policy-Validation/README.md) — check sample passwords against length, character-category, repetition, and prohibited-substring rules.
3. [Hospital Billing and Patient Classification](Project-03-Hospital-Billing-and-Patient-Classification/README.md) — calculate patient bills, apply the stated senior concession assumption, and classify final bills.

## Repository structure

- `index.html` — project directory website for GitHub Pages
- `Project-01-Food-Waste-Monitoring/` — first case study, code, and documentation
- `Project-02-Password-Policy-Validation/` — second case study, code, algorithm, pseudocode, flowchart, test cases, and output summary
- `Project-03-Hospital-Billing-and-Patient-Classification/` — third case study, code, algorithm, pseudocode, flowchart, test cases, and output summary

## Run Project 01

Open a terminal in the first project folder and run:

~~~text
python food_waste_monitoring.py
~~~

## Run Project 02

Open a terminal in the second project folder and run:

~~~text
python password_policy_validation.py
~~~

## Run Project 03

Open a terminal in the third project folder and run:

~~~text
python hospital_billing.py
~~~

Project 03 uses an assumed 10% concession for patients aged 60 or older and assumed LOW, MODERATE, and HIGH billing bands, because the case-study description does not specify those exact policy values. These assumptions are documented in its README.

The programs use beginner-level Python concepts from the assigned syllabus. See each project's README for assumptions, run instructions, and test cases.
