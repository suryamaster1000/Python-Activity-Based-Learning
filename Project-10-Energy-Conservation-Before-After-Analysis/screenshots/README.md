# Screenshots — Project 10

`sample_output_preview.svg` is a designed preview, **not** an actual terminal screenshot.

To capture genuine evidence for submission:

1. Open a terminal in this project folder.
2. Run `python energy_conservation_before_after_analysis.py`.
3. Enter the four appliance examples from Test Case 1 in `test_cases.md`.
4. Capture screenshots showing the appliance-wise comparison and overall summary.
5. Save them in this folder as `energy_before_after_terminal_1.png` and, if needed, `energy_before_after_terminal_2.png`.
6. Keep values, units, and percentages readable.

Do not present the designed preview as a genuine terminal screenshot.
