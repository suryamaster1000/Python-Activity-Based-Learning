# Screenshots — Project 08

`sample_output_preview.svg` is a designed preview, **not** an actual terminal screenshot.

To capture genuine evidence for submission:

1. Open a terminal in this project folder.
2. Run `python weekly_electricity_consumption_matrix.py`.
3. Enter the 14 readings for the two-week Test Case 1 in `test_cases.md`.
4. Capture screenshots showing the weekly report, high-usage alerts, and overall summary.
5. Save them in this folder as `electricity_matrix_terminal_1.png` and, if needed, `electricity_matrix_terminal_2.png`.
6. Keep all totals and units readable.

Do not present the designed preview as a genuine terminal screenshot.
