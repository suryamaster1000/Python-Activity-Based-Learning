Food Waste Monitoring System

Case Study 53 · Python ABL

A console program that tracks meals prepared and served over seven days, calculates leftovers and wastage percentages, and warns when daily wastage exceeds 10%.

Objectives

  • Calculate leftover meals each day.
  • Calculate daily food wastage percentage.
  • Identify days with high wastage.
  • Summarize weekly meal totals and overall wastage.

Formula

Leftovers = Meals prepared − Meals served

Wastage % = (Leftovers / Meals prepared) × 100

Files

  • Python program
  • Full project documentation
  • Algorithm and pseudocode

Run the program

Install Python 3, download food_waste_monitoring.py, open a terminal in its folder, and run:

python food_waste_monitoring.py
