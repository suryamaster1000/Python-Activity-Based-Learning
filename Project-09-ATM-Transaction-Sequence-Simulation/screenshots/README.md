# Screenshots — Project 09

`sample_output_preview.svg` is a designed preview, **not** an actual terminal screenshot.

To capture genuine evidence for submission:

1. Open a terminal in this project folder.
2. Run `python atm_transaction_sequence_simulation.py`.
3. Enter the starting balance and the exact menu sequence from Test Case 1 in `test_cases.md`.
4. Capture screenshots showing the transaction decisions and final history/summary.
5. Save the images in this folder as `atm_simulation_terminal_1.png` and, if needed, `atm_simulation_terminal_2.png`.
6. Keep the session sequence and final balance readable.

Do not present the designed preview as a genuine terminal screenshot.
