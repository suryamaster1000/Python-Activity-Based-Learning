## Overview

This repository contains 10 small Python projects created for Activity-Based Learning (ABL). Each project applies Python programming concepts to a practical, student-friendly problem.

## Project List

1. **Food Waste Monitoring System** — Records and reviews food-waste information to help identify waste and encourage responsible use of food.
2. **Password Policy Validation** — Checks whether a password meets a set of basic password rules.
3. **String-Based Examination Answer Evaluation** — Uses string operations to compare and evaluate examination-answer text.
4. **Multi-Stage Examination Eligibility** — Checks student eligibility based on multiple conditions or stages.
5. **Tuple-Based Product Catalogue Audit** — Uses tuples to organize product details and review a catalogue.
6. **Student Feedback Sentiment Scoring** — Examines feedback text and assigns a simple sentiment score using word-based rules.
7. **Student Marks Matrix Analysis** — Organizes marks in a matrix and performs basic analysis.
8. **Weekly Electricity Consumption Matrix** — Stores weekly electricity-consumption data in a matrix for comparison and analysis.
9. **ATM Transaction Sequence Simulation** — Simulates a sequence of basic ATM transactions.
10. **Energy Conservation Before-and-After Analysis** — Compares energy-use data before and after conservation measures.

## How to Run

1. Install Python 3 on your computer.
2. Open a terminal or command prompt.
3. Navigate to the folder of the project you want to run.
4. Run its Python file. For example:

   ```bash
   python food_waste_monitoring.py
   ```

   Use the Python filename listed inside the relevant project folder. On some systems, use `python3` instead of `python`.

## Conclusion

These projects demonstrate how Python can be applied to everyday scenarios through simple programs, structured data, string processing, conditions, and matrix-based analysis. They are intended for learning and practice as part of the ABL coursework.
